# Portfolio

This repository now contains a responsive portfolio website for Lutho.

## Overview

The site is a single-page portfolio built with HTML, CSS, and JavaScript. It highlights:

- software development experience
- Java, JavaScript, Python, Swift, and SQL skills
- personal background and strengths
- contact section for professional engagement

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — styling and responsive layout
- `script.js` — mobile navigation toggle and footer year

## Run locally

Open `index.html` in a browser, or serve the project with a small local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Update the text in `index.html` to reflect your real projects, experience, and contact details.
